## AS4837 到底是什么线路，为什么它便宜还比 163 稳

AS4837 是中国联通在国际出口侧的一段自治网络编号。从美国机房往国内回程，数据包在跨境那一两跳进入国内之前会经过 AS4837 节点，再转交国内骨干网。这段跨境线路负载相对低，海缆扩容之后带宽也足，延迟和丢包比全挤在 163 普通骨干上的回程要稳。

这里有个新人几乎都踩过的误区：业内说的“联通 4837”，指的是跨境段走 AS4837，跟你家里那条联通宽带是不是 4837 没有半点关系。有人拿测速脚本一看“我这边也显示 4837”，那串数字是国内骨干段的，跟跨境优化不是一回事。判断一条线是不是真 4837，看的是回程进国内那一两跳，下一节单独讲怎么测。

价格便宜的根子在成本。4837 是联通的大路基普通骨干，带宽给得足，商家采购成本低，所以敢在同样价钱下把口子开到 1Gbps。同样是美西 1 核 1G 的小机器，CN2 GIA 动辄 5 美元一个月起，4837 能做到 2 到 3 美元；换成人民币口径，六六云那台 1 核 1G、1Gbps、1TB 月流量的 4837 标 45 元一个月。

延迟别抱幻想。美西到国内的物理距离摆在那儿，170ms 到 190ms 是这条路的常态，谁也别想跑出 50ms。六六云 4837 的公开测评里，测评者用电信宽带测到 186ms，北京、上海、广州、成都四地的电信、联通、移动回程全部落在 AS4837 上。想要低延迟，买香港或日本去，美西给不了。

## 怎么验证你买到的确实是 AS4837

一条命令：`mtr -rzn 目标IP地址`。

三个要点。看回程，不是去程，方向是服务器到你本机，回程对实际体验的影响更大。看进入国内的第一跳或第二跳的 AS 编号是不是 4837。测试目标要选电信或移动的家庭宽带地址，如果目标本身就是联通，国内段全程都是 4837，反而分辨不出跨境段有没有做优化。

别只看商家给的测速图，那种图是挑过的时段、挑过的节点跑出来的，参考价值有限。真要看，让他给 Looking Glass，或者自己拿测试 IP 跑。

六六云公开的测试地址里，美国原生 IP-4837 那台是 154.29.146.1，双 ISP 的 4837 是 38.79.117.254。下单前先拿这两个地址从你自己的网络上跑一遍 mtr 和 ping，晚上八点到十点再跑一次，这比看十篇测评管用。机器买回来之后也别急着信，自己监控一两天，看丢包率是不是只在晚高峰抬起来，还是全天都在抖。前者是线路的正常表现，后者说明这台母机有问题，该开工单开工单。

## 短板、限速，以及哪些人别买这条线

晚高峰的劣化是整条 4837 的通病，不是某一家的锅。2022 年 3 月之后，行业里普遍观察到这条线晚高峰的延迟和丢包有所上升，早几年那种“神线”表现已经没有了。它现在的水平是“够用且便宜”，不是“又快又稳又便宜”。春节、大型直播这类极端时段，4837 会明显掉档，这时候拿它跑实时业务就是给自己找麻烦。

超流量限速得提前问清楚。4837 这个价位段的通行做法是月流量跑完之后限速到 1Mbps，差不多回到拨号上网的速度。六六云各档超出流量之后怎么处理，我在商品页上没有看到明确写法，下单前在商品页或者工单里问一句，别等跑超了才发现整台机器变龟速。

硬件别期待。这个价位的机器都是共享核，第三方对六六云方案的总结也是“硬件配置较低、方案配置单一”。跑 nginx、跑几个容器、做转发没问题，跑编译、跑重负载数据库就知道疼了。

有四类人我不建议买这条线。做跨境直播推流、高频交易的，晚高峰抖动直接影响业务，上 CN2 GIA 或者 IPLC。电信用户且晚高峰一点都不许卡的，9929 起步。要大硬盘大流量做下载站、做中转的，1 到 2TB 的月流量撑不住，超了就是 1Mbps。想跑 Windows 的，1 核 1G 带不动，别试。
